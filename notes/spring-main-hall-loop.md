## 三轮修改

第一轮统一浅暖木色、梁柱纹理方向、草地与地板采样，并调整三维树冠与树根阴影。第二轮修复顶面、草地采样的比例失真，保留屋面真实尺度坐标；花冠从灰紫恢复暖珊瑚色，打散规则叶团。

第三轮尝试将共享材质改为分层采样：中尺度颜料、宽幅留白、局部积色边界与独立轴向木纤维。细纸纹由实时后处理统一叠加，避免同一 RGB 采样中的纸纹和划痕在多个尺度重复。树冠保留封闭三维体积和原有包围盒，合批时保留整冠高度与局部颜料属性，春季花色与秋季金赭色独立切换。

第三轮首次内部实拍发现过大的留白色块与尖锐叶簇；正式评审前已在同轮内修正并重拍。失败画面、运行数据与源码快照保存在 `rounds/round-3-prejudge-material-failure/`，未计入正式评分。该轮修正后恢复中尺度颜料、连续低对比留白、蓝灰顶面底色和圆润叶簇，但独立评审仍发现木材横格和树冠变平。该方案仅保留在 `rounds/round-3-source.zip` 中，未留在最终运行版本。三轮相机矩阵、FOV、尺寸、季节、时间与 golden 哈希已再次核对。

## 当前仍有差距

第二轮的暖珊瑚花色、较安静的草地和顶面比例修正予以保留。叶簇仍偏大块，缺少细小叶片、花瓣边缘、淡纸留白及更强的上下色层；梁柱仍有斜向交叉纹，地板、树皮、石面与水面仍缺少参考中的选择性积色。秋季草地比第一轮更平静，但树冠仍偏柠檬黄、金赭层次不足。没有将其他视角宣称为与 golden 精确匹配。

## 复验

启动本地静态 HTTP 服务后运行：

```sh
TEST_URL=http://127.0.0.1:4187/ STYLE_SCENE=entrance STYLE_REPORT=tests/spring-main-hall-verification.json node tests/courtyard-style.cjs
TEST_URL=http://127.0.0.1:4187/ node tests/verify.cjs
TEST_URL=http://127.0.0.1:4187/ node tests/capture.cjs
```

专项脚本在全新的桌面与窄屏上下文中验证春季固定截图重复一致、四季画面、茶室懒加载与缓存、路线和帧率。默认不传 `STYLE_SCENE` 时仍检查秋季中庭；`STYLE_SEASON` 可以显式指定固定截图与性能采样季节。

本地循环采集器另可运行：

```sh
TEST_URL=http://127.0.0.1:4187/ node .dream-loop/spring-main-hall/capture.cjs review --all
```

目标、每轮实际截图、叠图、差异图、运行 JSON、实现笔记、源码快照与初始修改备份位于忽略的 `.dream-loop/spring-main-hall/`。完整 golden 不参与网站运行；材质局部采样来源与生成脚本见 `SOURCES.md`。
