## 主要修改

共享材质从单一明暗调制扩展到保留颜料色彩的大、中、小尺度笔触，校准暖木、灰泥、矿物石色与纸面留白。水彩后处理作用于实时场景与茶室。秋季植被加入赭色层次，其余季节保持独立配色。

新增三维叶簇、不规则石块与共享倒影颜料处理。倒影仍来自真实建筑；池塘具有局部浅色留白与青绿色洗。中庭注视目标 y=5.76，位置仍为 [-4, 6.85, 0]。四季庭院和三个房间共 18 张响应式 WebP 由新版场景重建。

## 仍有差距

树冠仍能看出实体叶团，缺少 golden 的层叠叶片与自然笔触边界。水面偏平滑，局部倒影仍有角状粗条。木材、石材和灰泥的颜料层与明亮留白，尚未达到参考图的组织方式。

## 复拍

启动项目本地 HTTP 服务后，可运行：

```sh
TEST_URL=http://127.0.0.1:4173/ node tests/courtyard-style.cjs
TEST_URL=http://127.0.0.1:4173/ node tests/capture.cjs
TEST_URL=http://127.0.0.1:4173/ node .dream-loop/courtyard-autumn/capture.cjs review --all
```
